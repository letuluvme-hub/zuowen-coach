# zuowen-coach · 初中作文陪练

一个帮初中生写记叙文的 AI Skill。它不替学生写作文，而是带学生走完九步：审题、认题型、找素材、列提纲，最后把提纲拆成一份能直接照着写的"句子清单"。每一步都配一招可以迁移到其他题目的写作方法。

以上海中考作文（600 字左右的记叙文）为基准，也适用于全国初中的命题和半命题作文。

## 它解决什么问题

| 学生的困难 | 对应的步骤 |
|---|---|
| 没东西写，反复用同一个素材 | 四个抽屉找素材，把常见答案反过来想 |
| 一篇写好几个小时 | 选材和提纲限时完成，每段限时写 |
| 有了提纲还是下不了笔 | 拆节拍：每段拆成几拍关键词，生成句子清单 |
| 提纲前后对不上 | 连起来读：检查主角、事件、细节、指代 |
| 下一道题又不会了 | 四类题型加九招，每一招都有名字，换一道题照样能用 |

## 目录结构

```
zuowen-coach/
├── SKILL.md                         # Skill 主文件（Claude 等支持 Skill 的平台使用）
├── PROMPT.md                        # 通用提示词（ChatGPT、Kimi、豆包、DeepSeek 等直接粘贴）
├── references/
│   ├── four-types.md                # 四类题型：信号词、结构、节拍、易错点、历年真题归类
│   ├── nine-methods.md              # 写作九招，以及关键词变句子的示范
│   ├── coaching-playbook.md         # 卡点诊断、对话示范、提纲诊断、家长建议
│   └── guide-page-spec.md           # 如何为新题目生成交互引导网页
└── assets/
    └── guide-page-template.html     # 引导网页模板（单文件，可直接打开）
```

## 怎么用

**在 Claude 里**：下载打包好的 `zuowen-coach.skill`，在 Claude 的 Skills 设置里上传；或者把整个文件夹放进 Claude Code 的 skills 目录。之后直接发作文题目即可，比如"老师布置了《这里也有乐趣》，我不知道写什么"。

**在其他 AI 里**：打开 `PROMPT.md`，把分隔线以下的内容粘贴到自定义指令或系统提示词里，或者作为对话的第一条消息发送。

**生成引导网页**：对 AI 说"按 zuowen-coach 的模板，为《××××》做一个引导页"，它会参照 `references/guide-page-spec.md` 替换模板数据。模板可以直接用浏览器打开看效果。

## 三条原则

1. **不代写。**示范最多一两句，而且用和学生无关的故事。
2. **能力优先。**前面用选项降低开口门槛，关键的两步（连起来读、拆节拍）必须学生自己写。
3. **逐步撤掉辅助。**同一类题型，第一次全套辅助，第二次只给问题，第三次只给九招清单。最终目标是学生不再需要它。
