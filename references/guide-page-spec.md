# 生成引导网页（模式 B）

`assets/guide-page-template.html` 是一个完整可运行的单文件页面，题目为《不拘一格的美》，属于发现转变型。为新题目做页面时，复制这个模板，替换下面列出的内容。

## 页面流程（不要改）

封面 → 1 圈题眼 → 2 立靶子 → 3 找素材 → 4 第一眼 → 5 那一刻 → 6 结尾 → 7 连起来读 → 8 拆节拍 → 9 交前三查 → 句子清单

设计原则：
- 前 6 步以按钮为主，每组带"其他，我自己写"
- 第 7、8 步必须自己写关键词，这是练写作能力的部分
- 每步底部配一张招式卡（`METHODS`）
- 桌面端右侧显示实时生长的提纲，手机端每步底部显示"这一段会写成"
- 最终页先给句子清单，再给四段提纲，并写明写作顺序和每段写完后的自查问题
- 视觉母题是作文稿纸：题目文字写在格子里，有一个字跳出格子

## 必须替换的内容

| 位置 | 内容 | 说明 |
|---|---|---|
| `<title>`、封面 `.hero` 的格子字、`.mark`、最终页 `mini-cells` | 新题目 | 封面让题眼对应的字跳出格子 |
| `KEY` | localStorage 键名 | 每个题目用不同的键，例如 `zuowen_<拼音>_v1`，避免不同题目的进度混在一起 |
| 第 1 步 `.key` 文案 | 题眼解释 | 写清题目要什么、不要什么 |
| `PAIRS` | 三组扣题对比 | 每组一句扣题、一句写偏，附一句原因。三组分别针对：写常规答案、列清单、只说结论不写细节 |
| `REVERSE` / `STANDARDS` | 第 2 步"靶子"选项，以及对应的反向问题 | 发现型是"原来的标准"；其他类型见下文 |
| `CATS` | 四个抽屉：items、traitQ、traits、b2 | 按新题目改写选项，"一个人"类别会自动把"它"换成"他" |
| `FIRST`、`REACT` | 第 4 步选项 | 按题型改，见下文 |
| `TIME`、`EVENT`、`PERSON_TIME`、`PERSON_EVENT` | 第 5 步选项 | 事件选项之间不要互相矛盾 |
| `DETAILS` | 细节类型，以及追问 | 通常不用改 |
| `HIDE`、`AFTER` | 第 6 步结尾选项 | 按题型改 |
| `paras()` | 四段提纲的拼句模板 | 改成新题型的句式 |
| `beatDefs()` | 第 8 步节拍 | 照 `four-types.md` 里对应题型的节拍表来写，示范统一用一个和学生无关的故事 |
| `TRANSFER` | 最终页"换一道题试试" | 选一道同类型的真题，演示九招怎么走 |
| 各 section 的 `h2` 和 `.sub` 文案 | 每步的标题 | 按题型改，见下文 |

## 四类题型要改的步骤

| 步 | 发现转变型（模板现状） | 过程坚持型 | 情感关系型 | 开端影响型 |
|---|---|---|---|---|
| 2 立靶子 | 你心里的美原来是什么样子 | 你想做成什么？最难的是哪一点 | 这个人平时在你眼里是什么样子 | 现在的你，喜欢或在做什么 |
| 4 第 4 招 | 第一眼：先抑 | 第一次：一次具体的失败 | 平时：一次小摩擦或误会 | 起点：最开始那件事（慢镜头放在这一步） |
| 5 | 那一刻：转变（慢镜头） | 关键那次：最想放弃时（慢镜头） | 那个细节（慢镜头） | 慢慢长大：一两个后续片段 |
| 6 收 | 原来 + 藏在 + 从此 | 结果 + 明白了什么 + 现在 | 现在想起 + 这份情是什么 + 一个动作 | 伏笔呼应 + 这只是开始 |
| 7 通 | 主角一个还是一堆、那一刻是不是一件事、细节具不具体 | 加一问：几次尝试有没有写出不同 | 加一问：两个人是不是都有动作 | 加一问：起点埋的东西，结尾有没有出现 |

招式卡第 4 招的名字和印章也要跟着改：发现型"抑"，过程型"递"，情感型"细"，开端型"呼"。

## 技术要求

- 单文件 HTML，CSS 和 JS 内联，不依赖任何外部脚本
- 字体用非阻塞加载（`media="print" onload="this.media='all'"`）。加载不到时会自动退回系统字体，保证在中国大陆不会白屏
- 进度存在 localStorage 里，所有读写都包在 try/catch 中
- 支持深色模式和"减弱动效"设置，适配手机安全区
- 上线前完整走一遍流程：从第 1 步走到句子清单，确认每一步的必填提示都正常，没有报错
